# Agent instructions

Commits, pull requests and where code may come from are in [CONTRIBUTING.md](CONTRIBUTING.md). Wider conventions that are not specific to this project live in the guidelines your global agent instructions point at. Read the smallest file that answers the decision in front of you; do not load the folder.
