# Agent instructions

The conventions for this repository are in [CLAUDE.md](CLAUDE.md). Read that file, then the one file in `docs/decisions/` that covers the area you are working in.

Wider conventions that are not specific to this project — commits, pull requests, branches, backend and frontend defaults — live in the guidelines your global agent instructions point at. Read the smallest file that answers the decision in front of you; do not load the folder.
